## 🚀 Hướng dẫn Bắt đầu

### 1. **Thiết lập Môi trường Phát triển**

```bash
# Cài đặt dependencies
npm install -g @aivin-labs/sdk
```

### 2. **Tạo Plugin đầu tiên của bạn**

```bash
# Tạo tương tác
aivin create

# Hoặc để AI tự sinh src/main.ts từ mô tả nghiệp vụ
aivin plugin make "Tóm tắt ticket hỗ trợ và gắn nhãn mức độ khẩn cấp"
```

Toàn bộ năng lực nền tảng (AI, vector search, task, storage, realtime...) đều đi qua `ctx.sdk` —
xem [docs/SDK.md](./SDK.md).

### 3. **Phát triển & Test**

```bash
# Khởi động local: gRPC server thật + HTTP test shim ở :4001
aivin start

# Test plugin của bạn locally
curl -X POST http://localhost:4001/invoke \
  -H 'content-type: application/json' \
  -d '{"input":{"message":"Xin chào"}}'
```

### 4. **Triển khai & Kiếm tiền**

```bash
# Deploy lên test instance trước để kiểm chứng
aivin test

# Triển khai lên org của bạn
aivin deploy

# Đặt giá trong dashboard
# Bắt đầu kiếm tiền ngay lập tức!
```
